# *** Eyer MCP server ***

There are two versions of the Eyer MCP server

1. MCP server with HTTP authentication - eyer-mcp-server-auth.zip
2. MCP server without HTTP authentication - eyer-mcp-server.zip

You find instructions on how to deploy the MCP server at https://customer.support.eyer.ai/servicedesk/customer/topic/cea73890-22c8-416e-9db9-54e3554cdd6a
